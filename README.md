# 📦 Digital Warranty & Asset Tracking System

A web-based application to manage product warranties and track assets efficiently.
Users can store product details, monitor warranty status, and get reminders before expiry.

---

## 🚀 Features

* 📄 Add and manage product details
* ⏰ Track warranty expiry dates
* 🔔 Reminder system for expiring warranties
* 🔐 User authentication (login/signup)
* 📊 Dashboard for asset overview

---

## 🛠️ Tech Stack

**Frontend:**

* HTML
* CSS
* JavaScript

**Backend:**

* Node.js
* Express.js

* MongoDB

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/AP24110010419/Digital-Warranty-Asset-Tracking-System.git
```

2. Navigate to the project folder:

```
cd Digital-Warranty-Asset-Tracking-System
```

3. Install dependencies:

```
npm install
```

4. Start the server:

```
npm start
```
